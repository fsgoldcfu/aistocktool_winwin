# 美股資料限流、淘汰統計與門檻調校

## 目的

本更新處理兩個不同問題：第一，防止美股固定池反覆下載日線資料而觸發 Twelve Data HTTP 429；第二，令「今日心水」在零推薦時顯示資料覆蓋率和各條件淘汰數，而不是把所有零推薦都誤解為市場無機會。

> **零推薦與資料不可用是不同結果。** 當掃描顯示 `44/44` 已完成分析而仍然是零推薦，才可開始討論規則是否嚴格；若只完成例如 `8/44`，代表資料覆蓋不足，不能推論整個固定池沒有機會。

## 美股日線保護規則

| 項目 | 預設值 | 行為 |
|---|---:|---|
| Fresh history cache | 15 分鐘 | 同一 symbol／期間在同一 Vercel instance 不重複下載。 |
| Stale fallback cache | 6 小時 | 收到 429、預算用盡或短暫網路問題時，只使用最後一份有效日線，不把缺資料當作合格訊號。 |
| Twelve Data 歷史請求最小間隔 | 8,000 ms | 未快取請求會單一排隊，不會平行爆發。 |
| 每 15 分鐘歷史請求預算 | 8 | 保護低額度 provider；未取到的股票會標記資料不足，而不會再打 API。 |
| HTTP 429 cooldown | 15 分鐘 | provider 回傳 429 後暫停新日線請求；有 stale 日線才 fallback，否則跳過該股。 |

以下 environment variables 可在 Vercel 設定。除非已確認 Twelve Data plan 的實際限制，請保留預設值：

```text
TWELVE_DATA_MIN_INTERVAL_MS=8000
TWELVE_DATA_MAX_HISTORY_REQUESTS_PER_WINDOW=8
TWELVE_DATA_429_COOLDOWN_MS=900000
```

這些保護是 Vercel function instance 內的記憶體快取；serverless cold start 後不保證仍然存在。因此它是減少重複請求和防止 429 的保護，不是持久資料庫。若要在所有 cold start 都維持完整 44 隻日線，下一階段應將已收市日線每日一次同步到 Supabase 或部署靜態資料檔。

## 今日心水的新統計

美股時段刷新後，前端會顯示：

1. **資料覆蓋率**：已完成分析／固定池總數。
2. **日線來源**：本輪新取、15 分鐘快取、舊快取 fallback、限流／預算暫停數。
3. **請求預算**：本 15 分鐘窗口的已用／上限。
4. **Cooldown**：如果 provider 已回 429，顯示約餘下多久才會再嘗試。
5. **淘汰統計**：每隻股票只按照最後未通過的規則計一次，包括資料不足、事件風險、相對強度、過熱、止蝕／1.5R、結構可行性、成本後 HK$500、信心分數及 Tradeability Score。

## 門檻嚴格度的建議

| 規則 | 現時設定 | 建議 | 原因 |
|---|---:|---|---|
| 最低風險回報 | 1.5R | **保留** | 低於 1.5R 會削弱止蝕後的正期望基礎；不應因零推薦直接放寬。 |
| 初始止蝕上限 | 約 3% | **保留** | 槓桿／高波動短炒若放寬止蝕，需要用更低倉位和獨立回測，不能只為增加推薦。 |
| 成本後最低盈利 | HK$500 | **保留** | 這是使用者設定的每筆成本後目標；降低會增加訊號，但不能證明更穩陣。 |
| Confidence | 60/100 | 先保留 | 先以淘汰統計確認它是否佔大量、而且是否集中於接近門檻的 setup。 |
| Tradeability Score | 60/100 | 先保留；只做受控紙上測試 | 該分數要求流動性、相對強度、可交易波幅及風險回報同時合理。若完整資料覆蓋下連續 10 個掃描顯示它是主要淘汰原因，可另建 **55 分** 的紙上對照組，不應直接取代 60 分正式規則。 |

建議的決策順序如下：

1. 先收集至少 10 次美股正規時段的掃描摘要，並確保每次資料覆蓋率足以解讀；如 provider 額度不足，先改善資料持久化或額度。
2. 對每個淘汰類別記錄次數，特別是 `Tradeability Score`、`成本後淨盈利`、`止蝕或至少 1.5R`。
3. 若 Tradeability Score 是最大類別，而且大量候選分數介乎 55–59，才以紙上交易另行測試 55 分分組；同時保留 60 分為基準組。
4. 若 HK$500 是最大類別，先檢查本金、每筆資金、富途實際費用、美元／港元匯率是否正確；不要先降低 HK$500。
5. 若 1.5R／止蝕是最大類別，這代表短線結構空間不夠，應等待或改進入場觸發，而不是直接降低 R 倍數。
6. 以交易日誌比較兩組的成本後勝率、平均 R、期望值、最大回撤及樣本數。未有足夠樣本時，不改正式規則。

## 限制

淘汰統計是**規則診斷工具**，不是勝率預測。它能解釋為何系統拒絕一隻股票，不能保證放寬某條規則後會賺錢。資料來源包括 Finnhub 報價／新聞／業績和 Twelve Data 日線；任何 provider 限流、延遲或缺失都會降低掃描覆蓋率。

本文件以 2026-08-18 的專案設定為基礎。這是研究和系統分析，不是個人化投資建議。
